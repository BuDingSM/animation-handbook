# 加载开场

[在线演示](https://animation.xizanghuapi.cn/animations/03-page-transitions/preloader/)

## 它是什么

加载开场是访客进站时先看到的一块深色整页幕布，上面是 Logo、一个从 0 数到 100 的百分比和一条进度条。数字用先快后慢的节奏数到 100%，进度条跟着填满，到 100% 后，幕布在 0.55 秒里往上拉开，下面的页面一边淡入一边从下面 14 像素处浮上来。整个过程大约 3 秒，把等加载的时间变成一次品牌亮相。

## 什么时候用

- 品牌开场，想让访客进站第一眼就记住 Logo
- 图片和视频很多的重型页面，加载本来就需要等几秒
- 作品集首页和活动页，开场本身就是内容的一部分
- 任何想把等待变成亮相、而不是干等转圈的场合

## 工作原理

幕布是一块盖在页面上的深色层，页面一开始藏在它下面，透明并且往下沉了 14 像素。数字用 requestAnimationFrame 从 0 数到 100，缓动是先快后慢的三次方曲线：

```js
function step(now) {
  const p = Math.min((now - start) / total, 1);
  const e = 1 - Math.pow(1 - p, 3);   // easeOutCubic: start fast, end slow
  const n = Math.round(100 * e);
  num.textContent = n + '%';
  fill.style.width = n + '%';
  if (p < 1) requestAnimationFrame(step);
}
```

数到 100% 后，幕布加上往上平移的类，0.55 秒里整块滑出屏幕，同时页面加上显示的类，不透明度从 0 到 1、位置从下面 14 像素处回到原位，两个动作同时发生，所以幕布拉开和页面浮现是衔接在一起的。幕布滑出后藏起来，不再挡住页面。

数字的节奏很重要：先快后慢会让人觉得加载很快，因为前 80% 一眨眼就过去了，最后几位慢慢走完，反而显得踏实。反过来先慢后快，会让人觉得卡住了。

开启减弱动态效果后，直接跳过加载，显示页面。

## 关键参数

| 参数 | 默认值 | 效果 |
|-----------|---------|--------|
| 计数快慢 | 普通 | 数字从 0 数到 100% 的时间：快是 1 秒，普通 1.85 秒，慢 3 秒 |
| 幕布方向 | 往上拉开 | 幕布离开的方式：往上拉开最像幕布，往下拉开像放下一块板，直接淡出是原地消失 |
| 进度条颜色 | 橙色 | 进度条的颜色：橙色、蓝色、绿色，用品牌色最协调 |
| 到 100% 后多停半秒 | 关 | 开启时，数字到 100% 后多停半秒再拉开幕布，让访客看清 100% 再进站 |

## 生产注意事项

- **只在第一次进站时出现。** 每次刷新都重新加载一次会很烦人，记下来访客已经看过，之后进站直接显示页面。
- **计数不要造假太久。** 数字最好跟着真实的加载进度走，实在拿不到进度时，1.85 秒左右是最舒服的长度，超过 3 秒访客就开始不耐烦了。
- **给搜索引擎和无脚本访客留后路。** 页面内容不要只靠幕布拉开才出现，脚本没跑起来时页面也必须能直接看。
- **幕布拉开后要彻底藏起来。** 只滑出屏幕还不够，记得把它设成不可见，否则它还会挡住点击。
- **不要用加载开场藏慢接口。** 开场只能盖住资源加载的等待，不能用来掩盖接口本身很慢，接口慢要从接口上解决。
