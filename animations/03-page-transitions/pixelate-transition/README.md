# 像素化过渡

[在线演示](https://animation.xizanghuapi.cn/animations/03-page-transitions/pixelate-transition/)

## 它是什么
像素化过渡把从一个页面或图片到下一个的变化藏在大方形块后面。当前页面碎成不断变大的纯色块，趁看不清时换页，方块再缩小，直到新页面变清晰。看起来像一幅图在老式电子游戏里失去又恢复焦点。

## 什么时候用
- 图片画廊和作品集，一张图片到下一张之间
- 游戏、音乐和复古主题的网站
- 幻灯片和故事页，每一步都是一整张图片
- 落地页各部分之间俏皮的切换

## 工作原理
页面是预先画在隐藏画布上的图片。切换期间，每一帧把当前页面很小地画在第二张画布上，每个方块一个像素，打开平滑，这样每个像素从它方块中间取色；然后把它以关闭平滑的方式放大回完整尺寸，这样每个像素变成一个纯色方块：

```js
const bw = Math.ceil(w / b), bh = Math.ceil(h / b);          // b: the block size this frame
sctx.imageSmoothingEnabled = true;  sctx.drawImage(page, 0, 0, bw, bh);        // sctx draws on the small canvas
ctx.imageSmoothingEnabled = false;   ctx.drawImage(small, 0, 0, bw, bh, 0, 0, bw * b, bh * b);
```

方块大小跟随切换：从一个像素长到中间的最大尺寸再缩小回来，页面恰好在中间、方块最大的时候换掉。分步让方块大小依次停在几个尺寸上，而不是平滑生长：

```js
const k = p < .5 ? p * 2 : (1 - p) * 2;                       // p: 0 to 1 over the change
let b = 1 + (blockMax - 1) * k * k * (3 - 2 * k);
if (stepped) b = Math.max(1, Math.round(b / blockMax * 4) / 4 * blockMax);
```

一次切换按经过的时间进行，慢动作时长三倍，切换之间什么都不画。页面名是画布上方真正的按钮，所以它们永远不会像素化，保持易读、键盘可达。页面标题在网站字体加载完成后用网站字体画一次。减弱动态效果时，切换是一次短暂的普通淡入淡出。

## 关键参数
| 参数 | 默认值 | 效果 |
|-----------|---------|--------|
| 方块大小 | 中 | 切换中途方块有多大：小是 8 像素，中 16，大 28 |
| 速度 | 普通 | 一次切换需要多长时间：慢是 1.2 秒，普通 0.8 秒，快 0.5 秒 |
| 方块变化方式 | 平滑 | 平滑均匀地放大和缩小方块；分步依次停在四分之一、二分之一、四分之三和完整尺寸 |

## 生产注意事项
- **每帧两次小绘制。**把页面画小再用 `drawImage` 放大回来；永远不要在循环里读取并平均像素。让隐藏的页面画布最多是屏幕像素的两倍。
- **图片，不是实时页面。**画布无法像素化 HTML。对于真实页面，先给每个视图拍张照片（html2canvas 或服务端截图），或者只像素化主图、淡入淡出其余部分。用 View Transitions API 时，旧视图和新视图可以显示为图片，再由着色器或画布像素化。
- **WebGL。**一个把每个像素坐标取整到它方块的片元着色器（`floor(uv * blocks) / blocks`）一次就能像素化全屏视图；PixiJS 有现成的像素化滤镜。
- **保持文字可读。**把导航和按钮留在像素化区域之外，并保持切换短暂：它本来就是要把页面藏一会儿。
- **采样，不是平均。**小副本取每个方块中间附近的一个点，而不是平均整个方块，对于纯色方块来说足够接近。要真正的平均，把小画布的平滑质量设为中或高，成本更高。
- **减弱动态效果。**改用短暂的普通交叉淡入淡出。
