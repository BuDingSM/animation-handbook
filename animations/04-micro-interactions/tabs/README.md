# 标签页切换

[在线演示](https://matinmonshizadeh.github.io/animation-handbook/animations/04-micro-interactions/tabs/)

## 它是什么

标签页切换是在同一个位置放几组内容，点页签就换一组。底线是它的眼睛：一条蓝色的线滑到当前页签下面，告诉你现在看的是哪一组。内容换的时候旧的淡出、新的淡入，位置不动，所以页面不会跳。

演示里是价格页的三个页签：概览、价格、评价。点“价格”，底线 0.25 秒滑过去、变宽一点贴合页签，内容 0.2 秒淡出，0.1 秒后新内容从下面 8 像素处淡入。

## 什么时候用

- 价格页、设置页、商品详情这类“同位置多组内容”
- 想让用户在几组相关内容之间来回切换
- 页面空间有限，不想把所有内容都堆出来
- 需要一眼看出当前在看哪一组

## 工作原理

底线是一条绝对定位的色块，它的位置和宽度都跟着当前页签走：

```js
// 底线滑到当前页签下面，同时变宽或变窄
underline.style.left = tab.offsetLeft + "px";
underline.style.width = tab.offsetWidth + "px";
```

```css
.underline {
  transition: left .25s cubic-bezier(.65, 0, .35, 1),
              width .25s cubic-bezier(.65, 0, .35, 1);
}
```

内容切换分两步：旧面板 0.2 秒淡出，0.1 秒后新面板 0.2 秒淡入、同时从下面 8 像素处上来。页签的字色和粗细也跟着变：选中的是蓝色加粗，其他的是灰色。

## 关键参数

| 参数 | 默认值 | 效果 |
|-----------|---------|--------|
| 页签数量 | 三个 | 顶上放几个页签：两个、三个或四个 |
| 底线速度 | 中 | 底线滑到新页签用的时间：快是 0.15 秒，中是 0.25 秒，慢是 0.4 秒 |
| 内容切换 | 淡入 | 新内容怎么来：淡入（从下面 8 像素处淡入）或滑动 |

## 生产注意事项

- **底线要贴合页签的宽度。** 每个页签宽窄不一样，底线只动位置不动宽度，看起来就像没对准。
- **内容切换别太慢。** 0.2 秒淡入淡出正好；超过 0.4 秒，点页签会觉得拖沓。
- **页签之间差别大时别用标签页。** 如果每组内容都是独立页面，用户需要同时对比，就别藏在页签后面。
- **减弱动态效果时直接换。** 演示在 `prefers-reduced-motion` 下不滑动、不淡入，内容直接换。
