# 缓动曲线

[在线演示](https://animation.xizanghuapi.cn/animations/04-micro-interactions/easing/)

## 它是什么

缓动曲线决定一个动作在每一刻有多快：开头多快、中间多快、停下来之前多快。匀速移动从头到尾一个速度，看起来像机器；加了缓动，动作会先快后慢，停下来之前慢慢减速，看起来就像有重量、有惯性。

最常用的是缓出（ease-out）：开头快、结尾慢，适合任何需要“停得自然”的动作——卡片滑进来、面板打开、页面切换。两头慢（ease-in-out）开头和结尾都慢，适合来回走的动作；缓入（ease-in）开头慢、结尾快，适合东西飞走、离开屏幕。

## 什么时候用

- 任何元素从一处移到另一处、出现或消失时
- 弹窗、抽屉和页面切换，想让落点停得稳
- 想让界面感觉顺滑、不机械的任何地方
- 给速度配上一点拉伸，让快的动作看起来更快

## 工作原理

浏览器自带的 `cubic-bezier()` 就是一条缓动曲线，四个数字定出它的形状。演示里下面那块方块用的是缓出：

```css
.card {
  transition: transform 1s cubic-bezier(.22, 1, .36, 1);
}
```

同一条曲线也可以画出来：横着是时间，竖着是走过的路。匀速是一条斜直线；缓出的线先陡后平——开头走得快，结尾走得慢。演示页的“看内部”就是这张图，曲线是按当前选的设置实时画出来的。

速度最快时的拉伸是另一层动画：方块外层负责移动，内层在中段沿移动方向拉长到 1.28 倍、压扁到 0.82 倍，停下时恢复原形。两层分开做，移动和拉伸才不会互相打架。

## 关键参数

| 参数 | 默认值 | 效果 |
|-----------|---------|--------|
| 曲线 | 缓出 | 缓出先快后慢，停得最自然；两头慢开头和结尾都慢；缓入先慢后快，适合离开 |
| 速度 | 普通 | 走完这段路的时间：慢是 1.6 秒，普通 1 秒，快 0.6 秒 |
| 速度拉伸 | 开 | 速度最快时沿移动方向拉长到约 1.3 倍，停下时恢复原形 |

## 生产注意事项

- **移动只用 `transform` 和 `opacity`。** 改 `left`、`top` 或 `width` 会让浏览器每帧重新排版，动画会卡。
- **缓出是默认选择。** 拿不准用什么曲线时，先用 `cubic-bezier(.22, 1, .36, 1)`，它在绝大多数出现和移动的动作上都好看。
- **别给需要匀速的东西加缓动。** 进度条、倒计时、匀速滚动的跑马灯，用 `linear` 才诚实。
- **减弱动态效果时直接放到终点。** 演示在 `prefers-reduced-motion` 下不播放移动，直接显示落点。
