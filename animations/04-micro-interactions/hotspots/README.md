# 热点标注

[在线演示](https://matinmonshizadeh.github.io/animation-handbook/animations/04-micro-interactions/hotspots/)

## 它是什么

热点标注是在一张图上放几个会脉动的圆点：点一下，0.25 秒弹出一个说明气泡，从下方 6px 处升起来；点另一个点，旧气泡消失、新气泡出现；再点一次关掉。圆点每 1.57 秒扩出一个白圈，提醒访客「这里可以点」。

它把说明直接钉在了图上对应的位置，不用在图下面写一长段文字再让访客自己对号入座。看产品图时，点一下肩带就知道肩带有什么讲究，点一下前袋就知道前袋防水——图和说明永远在一起。

## 什么时候用

- 产品图、示意图、户型图、地图，一张图上有几个值得讲的地方
- 说明很短，一两句话能说清
- 想让访客自己探索，而不是被动看一长段介绍
- 手机上看图，图下面的文字离图太远、对不上号

## 工作原理

每个圆点是一个按钮，带「查看说明：部位名」的 `aria-label`。脉动是圆点上的两个白圈，用同一个关键帧、错开半个周期无限循环：

```css
@keyframes pulse{from{transform:scale(1);opacity:.75}to{transform:scale(2.5);opacity:0}}
.hs-dot::after{animation:pulse 1.57s ease-out infinite}
.hs-dot i{animation-delay:.785s} /* 第二个圈错开半个周期 */
```

点圆点时，气泡先按圆点的位置摆好：靠左的点气泡放右边、靠右的点放左边，小三角指着圆点；再加 `.show`，透明度 0 到 1、同时从下方 6px 处升到原位，0.25 秒、`easeOutCubic`。点另一个点时，同一个气泡换掉文字、挪到新位置——旧气泡不是关了再开，而是直接换内容，所以切换看起来是一次移动。气泡带 `role="status"`，读屏软件会读出新内容。开启减弱动态效果后，脉动停掉，气泡直接出现。

## 关键参数

| 参数 | 默认值 | 效果 |
|---|---|---|
| 脉冲速度 | 普通（1.57 秒） | 圆点扩出一个白圈的时间：快是 0.8 秒，慢是 2.4 秒 |
| 气泡位置 | 自动 | 气泡在圆点的哪一边：自动按圆点左右位置选，左侧或右侧固定一边 |
| 圆点大小 | 中（16px） | 圆点直径：小是 12px，大是 20px |
| 显示脉冲 | 开 | 圆点定时扩出白圈，提醒这里可以点 |

## 生产注意事项

- **圆点不要超过 5 个。** 再多图就变成满天星，访客不知道先点哪个；部位太多就分组，或者换一页讲。
- **气泡不要挡住圆点指着的部位。** 气泡放在圆点的另一边，小三角指着圆点；挡住了部位，访客就看不到你正在讲的东西了。
- **圆点要够大、好点。** 16px 是底线，手机上最好 20px；点不中的热点等于没有热点。
- **同一个气泡换内容，不要关了再开。** 点另一个点时直接换文字和位置，切换是一次移动；先关后开会闪两下，像卡住了。
- **GSAP 等价写法：** `gsap.fromTo(tip, {opacity: 0, y: 6}, {opacity: 1, y: 0, duration: 0.25, ease: "power3.out"})`；脉动用 CSS 动画即可。
