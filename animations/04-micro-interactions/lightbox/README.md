# 灯箱

[在线演示](https://animation.xizanghuapi.cn/animations/04-micro-interactions/lightbox/)

## 它是什么

灯箱是点缩略图放大看图的做法：点一下，页面 0.45 秒变暗，图片在中央放大；图片下方显示「第几张 / 共几张」，左右有箭头、右上有 ×。按箭头或键盘方向键换图，按 Esc 或点黑色背景关掉，关掉时图片按原路缩回缩略图。

它让访客不用离开当前页面就能看清大图。缩略图负责「有哪些图」，灯箱负责「看清这一张」，看完关掉就回到原来的位置，页面没动过。

## 什么时候用

- 作品集、商品图、案例照片、相册
- 缩略图太小，看不清细节的场合
- 一组图要一张一张翻着看
- 不想为了看大图就跳到新页面

## 工作原理

缩略图是真正的按钮，带「放大看：图名」的 `aria-label`。点开时分两层动：黑幕是盖满舞台的 `rgba(14,18,28,0.82)`，透明度 0 到 0.82 用 0.45 秒；图片从 0.7 倍、透明放大到原样，同一个 0.45 秒、`cubic-bezier(.22,1,.36,1)`：

```css
.lb-overlay{opacity:0;transition:opacity .45s cubic-bezier(.22,1,.36,1)}
.lb-overlay.show{opacity:1}
.lb-photo{transform:scale(.7);opacity:0;transition:transform .45s cubic-bezier(.22,1,.36,1),opacity .45s}
.lb-overlay.show .lb-photo{transform:scale(1);opacity:1}
```

计数、箭头和 × 的透明度过渡带 0.22 秒延迟，所以它们在打开的后半段才出现——先看到图，再看到操作。关掉是反向：先拿掉 `.show`，0.35 秒后把整个灯箱 `hidden`。打开时焦点移到 × 上，关掉时焦点回到刚才点的缩略图，键盘访客不会丢位置。Esc、方向键、点黑幕都能操作。开启减弱动态效果后，黑幕和图片直接出现和消失。

## 关键参数

| 参数 | 默认值 | 效果 |
|---|---|---|
| 打开速度 | 普通（0.45 秒） | 黑幕铺开、图片放大的时间：快是 0.25 秒，慢是 0.7 秒 |
| 背景暗度 | 中（0.82） | 页面变暗的程度：浅是 0.5，深是 0.95 |
| 切换方式 | 放大 | 换图时新图怎么进来：放大、淡入或滑动 |
| 显示计数 | 开 | 在图片下方显示「第几张 / 共几张」 |
| 循环切换 | 关 | 到最后一张时，下一张回到第一张 |

## 生产注意事项

- **关掉要按原路回去。** 图片缩回它来的那张缩略图，访客才知道「我回到了刚才的位置」；直接消失会让人愣一下，不知道自己在哪。
- **黑幕要能点、能按 Esc 关。** 只有关闭按钮的灯箱，手机访客很难点到那个小 ×；点黑幕关掉是最顺手的做法。
- **打开时把焦点移进去，关掉时还回去。** 焦点留在后面的页面上，键盘访客按 Tab 会跑到灯箱后面的链接上去，这是灯箱最常见的无障碍 bug。
- **图不要比屏幕大。** 大图限制在舞台的 72% 宽以内，手机上留出边距，否则图会顶到屏幕边缘，箭头也没地方放。
- **GSAP 等价写法：** `gsap.to(overlay, {opacity: 0.82, duration: 0.45, ease: "power3.out"})`；图片用 `gsap.fromTo(photo, {scale: 0.7, opacity: 0}, {scale: 1, opacity: 1, duration: 0.45, ease: "power3.out"})`。
