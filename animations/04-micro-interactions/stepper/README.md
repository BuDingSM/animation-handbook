# 步进器

[在线演示](https://matinmonshizadeh.github.io/animation-handbook/animations/04-micro-interactions/stepper/)

## 它是什么

步进器是左右两个按钮夹着一个数字的小控件：减号让数字减 1，加号让数字加 1。每次按下去，数字都会轻轻弹一下——先放大到 1.18 倍、变成蓝色，再用 0.25 秒缩回原样；按下的那半边也短暂地变成浅蓝。数字到最小或最大时，对应的按钮变灰、按不动。

它适合改小数字，比如买几件、几个人、几张票。数字一次只变一点，弹一下就是在告诉你「按到了，数字已经变了」，不用盯着数字确认。

## 什么时候用

- 购物车里的购买数量、订票时的人数
- 一次只改一点点的小数字（1 到 99 之间）
- 希望访客不用打开键盘就能改数字
- 旁边要实时显示总价的场合

## 工作原理

数字放在两个按钮中间，按钮是真正的 `<button>`，减号和加号各有 `aria-label`。按下去时先算新数字，夹在最小值 1 和上限之间，写进数字位，再给数字播一次弹跳：

```js
num.animate(
  [{transform: 'scale(1.18)', color: '#3b82f6'},
   {transform: 'scale(1)', color: '#f4f4f2'}],
  {duration: 250, easing: 'linear'});
```

弹跳用 Web Animations API 播：从 1.18 倍线性缩回 1，同时颜色从蓝回到原来的字色，0.25 秒。线性很关键——先快后慢的缓动会让弹跳看起来拖沓。按下的那半边加 `.pressed` 类变浅蓝，200 毫秒后拿掉。按钮的可用状态每次渲染都重算：到下限减号 `disabled`，到上限加号 `disabled`，变灰只是样式，键盘也按不动。开启减弱动态效果后，弹跳直接跳过，数字只换值。

## 关键参数

| 参数 | 默认值 | 效果 |
|---|---|---|
| 步长 | 1 | 按一次数字加几或减几：1、2 或 5 |
| 弹跳幅度 | 中（1.18 倍） | 数字弹起来时最大是原样的一点几倍：轻是 1.08，强是 1.3 |
| 速度 | 普通（0.25 秒） | 数字从弹起缩回原样的时间：快是 0.15 秒，慢是 0.4 秒 |
| 上限 | 9 | 数字最大能到多少：5、9 或 99；到上限时加号变灰 |
| 显示总价 | 开 | 在步进器下面显示数量乘以单价的总价 |

## 生产注意事项

- **弹跳幅度别超过 1.3 倍。** 再大就像在抖，数字本身都看不清了；1.18 倍是「感觉到了、但不打扰」的大小。
- **上限要真实存在。** 库存只有 5 件，加号到 5 就该停；没有上限的步进器，访客会一直按到一个荒唐的数字。
- **按钮必须真的 `disabled`，不只是变灰。** 只变灰色的按钮键盘还能按到，读屏软件也不会说它按不动。
- **数字变化要播报给读屏软件。** 数字位加 `aria-live="polite"`，读屏软件会在数字变后读出新值；但别每按一下都打断正在读的内容。
- **GSAP 等价写法：** `gsap.fromTo(num, {scale: 1.18, color: "#3b82f6"}, {scale: 1, color: "#f4f4f2", duration: 0.25, ease: "none"})`。
