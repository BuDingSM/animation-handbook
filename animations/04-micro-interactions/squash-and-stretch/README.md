# 挤压与伸展

[在线演示](https://animation.xizanghuapi.cn/animations/04-micro-interactions/squash-and-stretch/)

## 它是什么

挤压与伸展是动画里最老的一条道理：东西落地时压扁，起跳时拉长，身体就有了弹性。压扁和拉长不是随便变形——压扁多少，横向就宽多少，这样体积看起来不变，观众才觉得它是一团有弹性的东西，而不是一块被拍扁的橡皮泥。

演示里的小球从高处落下：落地瞬间压到最扁，离地时拉到最长，飞到最高点时恢复圆形。影子也跟着变：球越高，影子越小越淡，落地时影子最大最浓。

## 什么时候用

- 小球、角色、吉祥物弹跳或落下时
- 想让图标、按钮看起来活泼、有弹性
- 游戏里的跳跃、落地、受击反馈
- 加载中的小动画，想让等待不那么无聊

## 工作原理

小球的变形只用 `transform` 里的 `scale`，基准点定在脚底（`transform-origin: bottom`），这样压扁时底部不动，看起来像真的砸在地上：

```css
.ball { transform-origin: 50% 100%; }
/* 落地瞬间：纵向压到 0.65，横向拉到约 1.54 */
.ball.squash { transform: scale(1.54, 0.65); }
/* 起跳瞬间：纵向拉到 1.28，横向缩到 0.82 */
.ball.stretch { transform: scale(0.82, 1.28); }
```

横向永远是纵向的倒数（`1 ÷ 纵向`），体积就保住了。弹跳的高度一次比一次低：第一次跳满，第二次跳一半，第三次跳三成，像能量耗尽了一样。影子是另一个元素，用 `scale` 和 `opacity` 跟着球的高度变。

## 关键参数

| 参数 | 默认值 | 效果 |
|-----------|---------|--------|
| 弹跳力度 | 中 | 落地时压扁的程度：轻压到 0.8， 中压到 0.65，强压到 0.5；跳得越高，压得越扁 |
| 弹跳次数 | 两次 | 弹跳的回数：一次、两次或三次，一次比一次跳得低 |
| 速度 | 普通 | 一次弹跳的时间：慢是 1.4 秒，普通 0.9 秒，快 0.55 秒 |

## 生产注意事项

- **横向永远是纵向的倒数。** 只压扁不拉宽，东西看起来像被压坏了；只拉长不变细，看起来像被拉坏了。
- **变形基准点要在脚底。** `transform-origin: bottom`，压扁时底部贴着地面；基准点在中间的话，球会“沉进”地面。
- **别压得太狠。** 压到一半以下就很卡通了，界面里的小图标用“轻”就够了。
- **减弱动态效果时别弹跳。** 演示在 `prefers-reduced-motion` 下让小球停在地上。
