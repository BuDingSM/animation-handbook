# 跟随动作

[在线演示](https://animation.xizanghuapi.cn/animations/04-micro-interactions/follow-through/)

## 它是什么

跟随动作是指主体停下之后，它身上的部件还多晃几下才停。跑步的人突然刹住，头发和围巾还会往前飘一下；旗杆停住了，旗面还要晃几下。身体是“刹车”，软部件是“惯性”——两者不同步，动作才有重量感。

演示里的小圆人滑进来急停，头顶的旗帜和身后的尾巴被甩出去，停下后还晃大约半秒，一次比一次小，最后收住。尾巴比旗帜晃得更慢、幅度更大，因为它更软、更长。

## 什么时候用

- 角色跑动、滑行后急停时
- 旗帜、挂件、头发、围巾这些软部件
- 图标上有飘带、天线、尾巴一类的部件
- 想让急停看起来有惯性，而不是突然冻住

## 工作原理

身体的位置和部件的角度是两套算法。身体先加速、再匀速、到点急停；旗帜的角度是一根被身体加速度推着的弹簧：

```js
// 停下后（s 是停下后的秒数），角度按衰减的正弦晃动
flagAngle = -amp * Math.exp(-4 * s) * Math.cos(9 * s);
// 尾巴是更慢的弹簧，晃得更大、收得更慢
tailAngle = -amp * 1.2 * Math.exp(-3 * s) * Math.cos(7 * s);
```

`exp(-4s)` 让晃动一次比一次小，`cos` 让它来回摆。身体在动的时候，旗帜和尾巴先往运动的反方向歪——它们被甩在后面；身体一停，弹簧就开始晃。尾巴的频率更低（7 对 9），所以晃得更慢。

## 关键参数

| 参数 | 默认值 | 效果 |
|-----------|---------|--------|
| 晃动幅度 | 中 | 旗帜和尾巴被甩出去的角度：小是 15 度，中是 30 度，大是 45 度 |
| 晃动时间 | 中 | 晃动收住的快慢：短是 0.6 倍，长是 1.6 倍，越长晃得越久 |
| 晃动的部件 | 旗帜和尾巴 | 哪些部件跟着晃：旗帜和尾巴、只有旗帜或只有尾巴 |

## 生产注意事项

- **主体要急停，部件才晃得起来。** 主体慢慢减速停下，加速度不够，旗帜和尾巴就没东西可“跟”。
- **越软、越长的部件晃得越久。** 尾巴比旗帜慢，因为它更软；做设计时按这个直觉调参数就行。
- **晃动要收住，别一直晃。** 衰减指数保证它半秒左右停下；一直晃会让人觉得东西没拿稳。
- **减弱动态效果时一起停。** 演示在 `prefers-reduced-motion` 下让所有部件和主体同时停下。
