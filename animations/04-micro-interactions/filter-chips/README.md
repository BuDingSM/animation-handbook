# 筛选标签

[在线演示](https://animation.xizanghuapi.cn/animations/04-micro-interactions/filter-chips/)

## 它是什么

筛选标签是一排可以点开、点关的小药丸，放在列表上方。点一下标签就加上一个筛选条件，标签出现勾号、变成蓝色、稍微变宽；再点一次就拿掉。列表随即跟着变：符合条件的卡片留下，不符合的变淡到几乎看不见。点「全部」清空所有条件，列表恢复原样。

它和下拉筛选的区别是条件看得见、点一下就行，不用打开菜单再选。条件可以叠加，比如同时选「新品」和「免费」，只看又新又免费的东西。

## 什么时候用

- 商品列表、文章列表或图片库，想让访客不用翻页就缩小范围
- 筛选条件只有几个，而且经常换着组合试
- 想让当前筛了什么条件一眼就能看到
- 手机上空间紧张，放不下侧边筛选栏

## 工作原理

每个标签是一个按钮，带 `aria-pressed` 告诉读屏软件它是否选中。选中的标签加一个 `.on` 类：背景变浅蓝、边框和文字变蓝，勾号出现，左内边距变小让出勾号的位置，整颗标签因此宽了约 18px。宽度的变化用 `padding` 过渡，0.15 秒、`easeOutCubic`：

```css
.chip{transition:background-color .15s cubic-bezier(.22,1,.36,1),border-color .15s,padding .15s}
.chip.on{background:#dbeafe;border-color:#3b82f6;color:#3b82f6;padding-left:10px}
.chip .tick{display:none}
.chip.on .tick{display:inline}
```

过滤在点击时算一次：每张卡片带自己的标签，符合当前选中条件的留下，不符合的加 `.dim`，透明度从 1 降到 0.12。透明度过渡和标签用同一个 0.15 秒，所以标签变蓝和卡片变淡是同时发生的。选了多个标签时，默认「任一符合」就留下；改成「全部符合」则一张卡片必须同时带有所有选中的标签才留下。开启减弱动态效果后，过渡全部去掉，切换直接发生。

## 关键参数

| 参数 | 默认值 | 效果 |
|---|---|---|
| 速度 | 普通（0.15 秒） | 标签变蓝、卡片变淡的时间：快是 0.1 秒，慢是 0.3 秒 |
| 匹配方式 | 任一符合 | 选了两个标签时，符合其中一个就留下；改成「全部符合」则两个都要有 |
| 不符合的卡片 | 变淡 | 不符合的卡片留在原地、透明度降到 0.12；改成「隐藏」则直接从列表里拿掉 |
| 显示数量 | 开 | 在标签下面显示还剩几件商品 |

## 生产注意事项

- **不符合的卡片不要直接消失。** 变淡保留了列表的形状，访客一眼能看出「筛掉了什么」；直接隐藏会让卡片跳位，访客容易丢了位置。
- **「全部」不是一个普通标签。** 它是清空按钮：点它关掉所有条件，点别的标签时它自动熄灭。不要把它当成一个可以和其他标签同时选中的条件。
- **标签不要超过 8 个。** 再多就该换成分组筛选或下拉菜单，一排药丸放不下，手机上尤其如此。
- **只用颜色区分选中和未选中是不够的。** 勾号是选中状态的第二种信号，色盲访客也能看出来；读屏软件靠 `aria-pressed` 听到状态。
- **GSAP 等价写法：** `gsap.to(card, {opacity: 0.12, duration: 0.15, ease: "power3.out"})`；标签的宽度变化用 CSS 过渡即可。
