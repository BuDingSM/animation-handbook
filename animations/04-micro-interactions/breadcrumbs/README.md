# 面包屑导航

[在线演示](https://matinmonshizadeh.github.io/animation-handbook/animations/04-micro-interactions/breadcrumbs/)

## 它是什么

面包屑导航是内容上方的一串链接，标出你现在在网站的哪一层，比如「首页 › 课程 › 网页设计」。前面的都是链接，点一下回到上一层；最后一段是当前页，加粗、不加链接。

它解决的是「我在哪、怎么回去」：访客从搜索结果直接落到一个深层页面时，看一眼面包屑就知道这个页面属于哪一块，点上级就能回到列表，不用一路按返回键。

## 什么时候用

- 文章页、商品详情页、帮助文档等深层页面
- 网站层级超过两层，访客可能从中间某一层进来
- 想让访客不用返回键就能回到上一级
- 搜索结果直接落地到深层页面的场合

## 工作原理

面包屑按当前层级渲染：前面的每一级都是链接，中间用分隔符隔开，最后一级是带 `aria-current="page"` 的纯文本，加粗、不加链接。点上级时，层级先变，但内容不是立刻换——先给内容区加 `.swap` 让透明度在半个切换时间里降到 0，换成上一层的内容，再拿掉 `.swap` 淡回来：

```js
body.classList.add('swap');           // 淡出
setTimeout(() => {
  render(level);                       // 换面包屑和内容
  body.classList.remove('swap');       // 淡入
}, fadeMs / 2);
```

内容是在看不见的瞬间换的，所以不会看到新旧内容叠在一起。点列表里的卡片回到详情页时，面包屑恢复成三段。开启减弱动态效果后，切换直接发生，没有淡入淡出。

## 关键参数

| 参数 | 默认值 | 效果 |
|---|---|---|
| 分隔符 | › | 层级之间的符号：›、/ 或 → |
| 当前页样式 | 加粗 | 当前页和链接的区分方式：加粗，或变灰 |
| 切换速度 | 普通（0.25 秒） | 内容淡入淡出切换的时间：快是 0.15 秒，慢是 0.45 秒 |
| 显示分隔线 | 开 | 在面包屑和内容之间画一条分隔线 |

## 生产注意事项

- **当前页不要做成链接。** 点当前页跳到自己是最让人困惑的交互之一；当前页是纯文本，加粗就够了。
- **层级超过 4 层要收起中间的。** 写成「首页 › … › 上级 › 当前页」，全列出来一行放不下，手机上尤其如此。
- **面包屑是导航，不是标题。** 它应该放在内容上方、靠近顶部的位置，别把它当成页面的主标题用。
- **分隔符用字符，别用图片。** `›`、`/`、`→` 都是文本，读屏软件会跳过（`aria-hidden`），也不会在高清屏上发虚。
- **GSAP 等价写法：** `gsap.to(body, {opacity: 0, duration: 0.12, onComplete: () => { render(level); gsap.to(body, {opacity: 1, duration: 0.12}); }})`。
