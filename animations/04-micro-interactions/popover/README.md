# 弹出气泡

[在线演示](https://animation.xizanghuapi.cn/animations/04-micro-interactions/popover/)

## 它是什么

弹出气泡是点一下按钮，在按钮旁边跳出来的小面板。它和弹窗不一样：它很小，带着一个指着按钮的箭头，一眼就能看出它属于哪个按钮；它也不抢走整个页面，点一下外面就关掉。

演示里点“详情”，小面板在按钮右边 0.3 秒内滑出来，箭头指着按钮。面板里是标题、两行说明和取消、确定两个按钮，点确定、取消或面板外面都能关掉。

## 什么时候用

- 按钮旁边要放一段短说明或一两个快捷操作
- 筛选、排序、日历这类小面板
- 头像、图标旁边的小菜单
- 想让用户一眼看出面板属于哪个按钮

## 工作原理

小面板平时是透明的、不能点的；打开时 `opacity` 回到 1，同时从按钮方向滑进来 6 像素：

```css
.pop {
  opacity: 0; pointer-events: none;
  transform: translateX(6px); /* 从按钮方向滑进来 */
  transition: opacity .3s ease-out, transform .3s cubic-bezier(.22, 1, .36, 1);
}
.pop.open { opacity: 1; pointer-events: auto; transform: none; }
```

箭头是一个旋转了 45 度的小方块，卡在面板边上，只留两条边框，看起来就像个三角形。点外面关掉是靠监听整个文档的点击：点在面板外面就关，点在里面不动。`aria-expanded` 告诉读屏软件面板是开是关。

## 关键参数

| 参数 | 默认值 | 效果 |
|-----------|---------|--------|
| 出现方向 | 向右 | 小面板出现在按钮的哪一边：向右或向下 |
| 出现速度 | 中 | 小面板跳出来用的时间：快是 0.2 秒，中是 0.3 秒，慢是 0.5 秒 |
| 出现方式 | 滑入 | 小面板怎么来：从按钮方向滑入 6 像素、淡入或从 0.96 倍放大 |

## 生产注意事项

- **箭头要指着按钮。** 箭头歪了或指错了地方，用户就不知道这块面板属于谁。
- **别让面板出屏幕。** 靠近屏幕边缘的按钮，面板要换一边出现；演示里只有向右和向下两个方向，生产里要按位置自动换边。
- **点外面要能关，但别误关。** 打开按钮的那次点击不要冒泡到文档监听，否则面板刚开就关。
- **减弱动态效果时直接出现。** 演示在 `prefers-reduced-motion` 下不滑动，面板直接出现和消失。
