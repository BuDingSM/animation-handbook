# 即时校验

[在线演示](https://matinmonshizadeh.github.io/animation-handbook/animations/04-micro-interactions/inline-validation/)

## 它是什么

即时校验是表单里的边输边检查：邮箱没输对时，输入框 0.15 秒变成红框、浅红底，下面出现红色的感叹号和「格式不正确」；输对的瞬间，边框 0.25 秒变绿，右端弹出一个带白勾的绿圆，提示变成「格式正确」。

它把报错提前到了输入的时候，而不是等点提交才一次性报错。访客不用提交、报错、回来改、再提交地来回跑，错在哪、怎么改，当场就知道。

## 什么时候用

- 注册、登录、联系、结算等任何要填邮箱、手机号的表单
- 格式有明确对错的输入：邮箱、手机号、密码、邮编
- 想减少「提交了才发现填错了」的来回
- 移动端表单，改错成本尤其高

## 工作原理

输入框每次输入都跑一次格式检查，但有两个克制：空着不报（刚点进来还没输，报错是打扰），只输了一个字符也不报（第一个字符永远是不完整的邮箱）。从第二个字符起，不对就变红框：

```js
if (!value){ show(''); return; }          // 空着不报
if (value.length < 2){ show(''); return; } // 才输一个字不报
show(/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(value) ? 'ok' : 'err');
```

变红是边框变 `#E5383B`、底变 `#FFF1F1`，0.15 秒、`easeOut`；变绿是边框变 `#1E9E5A`，0.25 秒，右端的绿圆用 `cubic-bezier(.34,1.56,.64,1)` 从 0.4 倍弹出来——回弹曲线让勾号「啪」地一下出现，像盖了个章。焦点时边框从灰变深蓝、1.5px 变 2.2px，也是 0.15 秒。状态同时写在三处：边框颜色、图标（`!` 或 `✓`）、提示文字，色盲访客和读屏软件（提示区带 `role="status"`）都能收到。开启减弱动态效果后，变色直接发生，绿圆不弹。

## 关键参数

| 参数 | 默认值 | 效果 |
|---|---|---|
| 校验时机 | 边输边校验 | 什么时候检查：边输边校验、失焦后校验，或提交时校验 |
| 提示位置 | 下方 | 提示文字放在输入框下面，还是右边 |
| 错误提示 | 文字 + 图标 | 错了时除了变红框，是否显示文字和感叹号；改成「仅边框」则只变色 |
| 显示成功提示 | 开 | 输对时显示绿勾和「格式正确」；关掉后只变绿框 |

## 生产注意事项

- **空着和刚开始输的时候不要报错。** 访客刚点进输入框，什么都没输就看到红字，只会觉得被骂了一顿；从第二个字符起再报。
- **不要只用颜色区分对错。** 红绿色盲分不清红框绿框，图标（`!` / `✓`）和文字（「格式不正确」/「格式正确」）是必须有的第二、第三种信号。
- **报错文字要说怎么改，不只说错了。** 「格式不正确」后面最好跟一句「比如 hana@example.com」；只说「无效输入」访客不知道改什么。
- **失焦后校验和提交时校验是退路。** 边输边校验最及时，但有的输入（比如密码）边输边报会打扰人，这时改成失焦后再报。
- **GSAP 等价写法：** `gsap.fromTo(mark, {scale: 0.4}, {scale: 1, duration: 0.25, ease: "elastic.out(1, 0.3)"})`；边框变色用 CSS 过渡即可。
