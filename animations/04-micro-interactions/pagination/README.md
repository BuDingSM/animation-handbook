# 分页

[在线演示](https://matinmonshizadeh.github.io/animation-handbook/animations/04-micro-interactions/pagination/)

## 它是什么

分页是长列表底下的一排页码：当前页用一个蓝色圆圈标出来，两边是上一页、下一页箭头。点一个页码，圆圈 0.2 秒滑到新页码上；上面的列表先淡出、换成新一页的内容、再淡入。第一页时「上一页」变灰，最后一页时「下一页」变灰。

它把一个很长的列表切成一页一页，每页内容固定，访客知道自己在第几页、后面还有几页。和无限滚动不同，分页能直接跳到某一页，也能把某一页的链接发给别人。

## 什么时候用

- 搜索结果、文章列表、商品列表、评论列表
- 一页放不下，但访客可能想直接跳到某一页
- 想让每一页都有自己的链接，能分享、能回退
- 列表很长，一次全加载会很慢

## 工作原理

页码是 5 个 36px 的按钮，间隔 8px，排成一行。蓝色圆圈不是画在某个按钮上的，而是一个独立的绝对定位元素，放在所有按钮后面；当前页是第几页，圆圈就 `translateX((页码 - 1) * 44)` 移到第几个按钮后面，0.2 秒、`easeInOutCubic`：

```css
.pg-pill{position:absolute;width:36px;height:36px;border-radius:50%;background:#3b82f6;
  transition:transform .2s cubic-bezier(.65,0,.35,1)}
```

44px 是按钮宽度 36px 加上间隔 8px，所以圆圈每次正好滑一格；从第 3 页回第 1 页时一次滑 88px。列表换页分两步：先给列表加 `.swap` 让透明度在半个切换时间里降到 0，换掉里面的行，再拿掉 `.swap` 淡回来——内容是在看不见的瞬间换的，所以不会看到新旧内容叠在一起。当前页码按钮带 `aria-current="page"`，读屏软件会读出「当前页」。开启减弱动态效果后，圆圈直接跳过去，列表直接换内容。

## 关键参数

| 参数 | 默认值 | 效果 |
|---|---|---|
| 每页条数 | 3 条 | 一页放几行：3 条或 4 条 |
| 切换速度 | 普通（0.2 秒） | 圆圈滑过去、列表淡入淡出的时间：快是 0.15 秒，慢是 0.4 秒 |
| 页码样式 | 圆圈 | 当前页的标记形状：圆圈、方块或下划线 |
| 显示上一页 / 下一页 | 开 | 在页码两边放 ‹ › 两个箭头按钮 |

## 生产注意事项

- **圆圈要跟着页码滑，不要每个按钮各画一个。** 一个圆圈平移过去，访客的眼睛能跟上「从第 2 页到了第 3 页」；每个按钮自己变色，眼睛就不知道发生了什么。
- **列表内容要在透明度最低时换。** 先淡出、再换内容、再淡入；直接换内容再淡入淡出，会看到新旧两行叠在一起闪一下。
- **页码太多时要收起中间的。** 5 页可以全列出来，50 页就要写成 `1 … 4 5 6 … 50`，否则一行放不下。
- **第一页和最后一页的箭头要真的禁用。** 只变灰、不禁用的箭头按下去没反应，访客会以为按钮坏了。
- **GSAP 等价写法：** `gsap.to(pill, {x: (page - 1) * 44, duration: 0.2, ease: "power3.inOut"})`；列表用 `gsap.to(list, {opacity: 0, duration: 0.1, onComplete: swap})`。
