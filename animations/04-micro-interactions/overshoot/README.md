# 过冲回弹

[在线演示](https://matinmonshizadeh.github.io/animation-handbook/animations/04-micro-interactions/overshoot/)

## 它是什么

过冲回弹是指针或数值走到目标时，先冲过目标一点，再晃几下回弹停住。就像你把车开进车位时稍微开过了一点，再倒回来——那一下“过头”让落点看起来有惯性、有弹性，而不是死死地刹住。

演示里是一块仪表：指针从零出发，冲到目标的 110%，再来回晃两下，稳稳落在目标上。冲过目标的那段弧线涂成珊瑚色，目标位置有一条黄色刻度，一眼就能看出它冲了多远。

## 什么时候用

- 仪表、进度条、滑块走到一个新数值时
- 想让落点带一点弹性，而不是生硬地停住
- 数字从旧值跳到新值，想让变化显眼一点
- 任何“到站”的动作，想让它看起来有惯性

## 工作原理

指针的位置用一条带衰减的震荡公式算出来：

```js
// t 是从开始算起的秒数，target 是目标值
value = target * (1 - Math.exp(-4.6 * t) * Math.cos(10.5 * t));
```

开头 `cos` 是负的，数值就比目标大——这就是冲过去的那一下；`exp(-4.6t)` 让晃动一次比一次小，最后落在目标上。冲过多少由公式前面的系数定：演示里“小、中、大”分别对应约 5%、10%、25%。

弧线用 SVG 的 `stroke-dashoffset` 画：整条弧长算作 100，数值是多少，弧就亮多少；超过目标的那一段单独画成珊瑚色。指针只是一条绕圆心旋转的线，角度就是数值 × 180 度。

## 关键参数

| 参数 | 默认值 | 效果 |
|-----------|---------|--------|
| 冲过多少 | 中 | 指针冲过目标的幅度：小是目标的 5%，中是 10%，大是 25% |
| 目标值 | 70 | 仪表要停在的数值：50、70 或 90 |
| 速度 | 普通 | 指针从零走到目标的时间：慢是 1.8 秒，普通 1.2 秒，快 0.8 秒 |

## 生产注意事项

- **数值绝不能超过目标时别用过冲。** 比如账户余额、已用流量，显示出来的数字有一帧高于真实值都可能让人误解，这时用缓出（ease-out）就好。
- **冲得越大，晃得越久。** 25% 的大过冲看起来活泼，但也更卡通；仪表盘上 10% 左右通常正好。
- **弧线和指针要同步。** 两者都从同一个数值算出来，才不会出现弧线到了、指针还在晃的错位。
- **减弱动态效果时直接显示目标值。** 演示在 `prefers-reduced-motion` 下不摆动，直接落在目标上。
