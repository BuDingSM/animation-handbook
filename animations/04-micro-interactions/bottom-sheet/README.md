# 底部抽屉

[在线演示](https://matinmonshizadeh.github.io/animation-handbook/animations/04-micro-interactions/bottom-sheet/)

## 它是什么

底部抽屉是移动端最常见的面板：点一下，面板从屏幕底部往上滑出来，盖住屏幕下半部分，原来的页面还留在上面。用户看完详情、选好操作，往下一拖或点一下遮罩，面板就滑回去。

演示里点“查看详情”，订单面板在 0.4 秒内从底部升起来，占屏幕高度的 40%，背后盖一层半透明遮罩。面板顶上有根把手，抓住它往下拖，面板就跟着手指走，松手超过一半就关掉。

## 什么时候用

- 移动端要看详情，又不想离开当前页面
- 分享、操作、筛选、排序这类半屏面板
- 表单只占半屏，上面还要留着上下文
- 想让用户一眼看出面板是从哪里来的

## 工作原理

面板平时藏在屏幕下面，只露 0 像素；打开时 `translateY` 从 102% 回到 0：

```css
.sheet {
  position: absolute; left: 0; right: 0; bottom: 0;
  height: 40%; /* 占屏幕高度的 40% */
  transform: translateY(102%);
  transition: transform .4s cubic-bezier(.22, 1, .36, 1);
}
.sheet.open { transform: translateY(0); }
```

遮罩是另一个元素，`opacity` 从 0 到 0.36，点它就关。拖把手时先关掉过渡（`transition: none`），让面板跟着手指走；松手时看拖了多远——超过 80 像素就关掉，否则弹回去。高度用百分比定，所以在任何屏幕上都占同样的比例。

## 关键参数

| 参数 | 默认值 | 效果 |
|-----------|---------|--------|
| 高度 | 中 | 面板占屏幕的比例：矮是 30%，中是 40%，高是 60% |
| 打开速度 | 中 | 面板滑出来用的时间：快是 0.25 秒，中是 0.4 秒，慢是 0.6 秒 |
| 点遮罩关闭 | 开 | 点面板外面的半透明遮罩时，是否关掉面板 |

## 生产注意事项

- **面板内容要能滚动。** 高度只有 40%，内容一多就得在面板里滚动，别让面板自己变高。
- **拖动时关掉过渡。** 跟着手指走的时候 `transition: none`，否则面板会滞后于手指；松手后再恢复。
- **焦点要进面板。** 打开后把键盘焦点移到面板里，关掉后还回按钮；读屏用户才知道面板出现了。
- **减弱动态效果时直接出现。** 演示在 `prefers-reduced-motion` 下不滑动，面板直接出现和消失。
