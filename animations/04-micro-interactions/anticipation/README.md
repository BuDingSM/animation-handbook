# 预备动作

[在线演示](https://animation.xizanghuapi.cn/animations/04-micro-interactions/anticipation/)

## 它是什么

预备动作是“动之前先往反方向动一下”。跳之前先蹲，扔东西之前先把手臂往后摆，按钮飞出去之前先往反方向缩一点——观众看到这一下反向动作，就知道它要往哪边去了，突然的移动看起来就有了准备。

演示里的方块要向右冲：它先往左缩 44 像素，同时压扁、往后倾，像拉满的弓；再向右冲出去，带着一点拉长和过冲，晃一下落定。没有这一下预备，方块就像是突然被推了一把。

## 什么时候用

- 元素要突然移动、飞出或跳起时
- 角色、吉祥物要跳跃、冲刺或攻击时
- 按钮、卡片要飞向另一个位置时
- 任何“没有预告就动了会吓人一跳”的动作

## 工作原理

预备动作分三段，用一组关键帧写出来：

```css
@keyframes shoot {
  0%   { transform: translateX(0) scale(1, 1); }
  55%  { transform: translateX(-44px) scale(1.22, 0.76) rotate(-10deg); }
  85%  { transform: translateX(320px) scale(1, 1); }
  100% { transform: translateX(320px) scale(1, 1); }
}
```

第一段（0%→55%）是蓄力：往反方向缩，同时压扁、后倾，用 `ease-in-out` 慢慢做，大约 0.75 秒。第二段（55%→85%）是冲出去：只要 0.43 秒，用带一点过冲的曲线（`cubic-bezier(.34, 1.4, .64, 1)`），中段拉长。第三段晃一下落定。预备段比冲出去慢得多——蓄力要让人看清，冲出去要快。

## 关键参数

| 参数 | 默认值 | 效果 |
|-----------|---------|--------|
| 预备幅度 | 中 | 往反方向缩的距离：小是 24 像素，中是 44 像素，大是 70 像素 |
| 预备时间 | 中 | 蓄力用的时间：短是 0.4 秒，中是 0.75 秒，长是 1.2 秒 |
| 方向 | 向右 | 方块冲向哪一边：向右或向左 |

## 生产注意事项

- **预备要让人看清，冲出去要快。** 蓄力 0.75 秒、冲刺 0.43 秒这个比例很好用；反过来会显得拖沓。
- **预备幅度别太大。** 缩回去超过移动距离的三分之一，观众会以为它要往反方向走。
- **别给每个动作都加预备。** 只有突然的、大幅的移动才需要；小反馈（比如按压）加预备只会显得迟钝。
- **减弱动态效果时直接显示终点。** 演示在 `prefers-reduced-motion` 下不做冲刺。
