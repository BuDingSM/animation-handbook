# 文字蒙版

[在线演示](https://matinmonshizadeh.github.io/animation-handbook/animations/05-text-typography/text-mask/)

## 它是什么

文字蒙版是把字母当成镂空的窗户，窗户里面放一幅会动的画面。字母本身不动，只有里面的画面在动：上面是珊瑚色的天空和一颗黄色的太阳，下面是蓝色的海，几道白色的波纹慢慢流过，一艘小帆船横着划过去。字母外面也淡淡地透出同一幅画面，快到结尾时，外面的画面完全露出来，再悄悄暗回去，整个循环大约 4.7 秒。

## 什么时候用

- 需要一眼抓住人的大标题和品牌开场
- 主视觉标题里想把一句话和一幅画面合成一个东西
- 海报式的标题，画面本身就是标题的一部分
- 循环播放的开场，访客停留几秒就能看完一轮

## 工作原理

做法分两层。先在一张离屏画布上画会动的海景，再在另一张离屏画布上写白色的字，然后用 source-in 把海景叠到白字上，这样海景只留在白字的形状里面：

```js
maskCtx.fillStyle = '#fff';
maskCtx.fillText(word, w / 2, h / 2 + 6);
maskCtx.globalCompositeOperation = 'source-in';
maskCtx.drawImage(sceneCanvas, 0, 0);
maskCtx.globalCompositeOperation = 'source-over';
```

主画布先以很低的不透明度画一遍整幅海景，再把蒙版后的字画上去，最后给字母描一圈 4 像素的白边。外面那层海景的不透明度平时是 12%，在每个循环的 73% 到 82% 之间升到 100%，再在 90% 到 99% 之间回到 12%，用平滑插值过渡，所以整幅画面是慢慢露出来、再慢慢暗回去，而不是突然闪现。

海景本身由时间决定：太阳上下浮动 6 像素，波纹每 4.7 秒漂 240 像素，相邻两道方向相反，帆船每 4.7 秒横穿一次，云每 4.7 秒漂 60 像素。字号从 172 像素起，每次减 2 像素，直到整个词不超过 500 像素宽，这样换词之后也不会溢出。

CSS 也可以做简化版：把画面当成文字的背景，用 background-clip: text 裁剪到字母形状里。但 CSS 版做不到外面那层淡淡的整幅画面，也做不到结尾的露出，所以演示页用 Canvas 做完整版。

开启减弱动态效果后，只画一帧静止的画面，不再循环。

## 关键参数

| 参数 | 默认值 | 效果 |
|-----------|---------|--------|
| 画面 | 海洋 | 字里的景色：海洋是珊瑚色的天和蓝色的海，日落是橙色的天和紫色的海，森林是浅绿色的天和深绿色的海 |
| 文字 | OCEAN | 蒙版里的词：OCEAN、海洋、夏日，短词、大字最清楚 |
| 速度 | 普通 | 一个循环的时间：慢是 7 秒，普通 4.7 秒，快 3 秒 |
| 结尾露出整幅画面 | 开 | 开启时，字母外面的画面在每个循环快结束时完全露出来再暗回去；关掉后，外面一直淡淡的 |

## 生产注意事项

- **长词要先量宽度。** 字号固定时，一个长词会溢出容器。先量文字宽度再定字号，或者给词的长度设上限，短词效果最好。
- **Canvas 版要准备静态备用图。** 不支持 Canvas 或者访客开启了减弱动态效果时，放一张画好的静止图，不要留空白。
- **画面别太花。** 字里的画面细节太多时，字母就认不出来了。画面用大色块和慢动作，留给字母足够的辨认空间。
- **描边是认字的保险。** 白色描边让字母在画面最亮的时候也能看清，换深色画面时记得把描边换成深色。
- **CSS 简化版的写法：** `background: url(scene.jpg); background-clip: text; -webkit-background-clip: text; color: transparent;`，再给文字设一个纯色备用颜色。
