可变字体变形

一个词平滑地变粗、变细，还会倾斜。最适合标题。

1

看效果

它自己在动。暂停可以仔细看，打开慢动作可以看清动作的每个部分。

内部是这样的：这个词沿着一种字体的字重范围滑动，从常规到特粗，途中在几个位置停留；圆点显示它现在的位置。

「跳变」像两个独立字体一样从一种样式直接跳到下一种。「平滑过渡」会经过中间的每一种字重，因为一种可变字体包含了全部字重。

2

试一试

改一个设置，边动边看有什么不同。

3

复制提示词

把它粘贴到 ChatGPT、Claude 或 Cursor 等 AI 助手里，在你自己的项目中实现这个效果。

给[你的标题或词语]加一个可变字体变形效果。使用可变字体，它把一整套字重放在一个文件里，平滑地改变字重，让字母在你眼前变粗又变细，依次经过几种样式，在每种上短暂停留。如果设置里有，这个词在某些变化中还会倾斜：有自带斜体的字体效果最好，没有斜体的字体用轻微倾斜也可以。通过字体本身来改变字重，不要用缩放，这样文字才能保持清晰。如果访客开启了减弱动态效果，让这个词保持一种样式。 按下面列出的设置来做。
