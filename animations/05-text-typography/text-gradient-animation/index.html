文字渐变动画

颜色在静止的文字中流动。最适合标题。

内部是这样的：渐变填满了词后面的整个盒子，以淡淡的颜色显示，字母是让它透过来的洞。这条色带宽三倍，一直在后面滑过。

「硬接缝」的色带结束时的颜色和开始时不同，所以一道锐利的边缘会滑过字母。「无缝」结束在它开始的地方，所以颜色不间断地流动。

复制提示词

把它粘贴到 ChatGPT、Claude 或 Cursor 等 AI 助手里，在你自己的项目中实现这个效果。

给[你的标题或标志文字]加一个流动的彩色渐变。用渐变而不是纯色填充字母：把渐变画成文字的背景，只在字母形状内显示，并让文字本身的颜色透明。然后让渐变在字母后面不停移动，或像色轮一样转动，这样颜色就在字母静止时流过整个词。让渐变以它开始的颜色结束，这样循环就没有接缝。给文字设一个纯色备用颜色，以防浏览器不支持把背景裁剪到文字上。如果访客开启了减弱动态效果，让渐变保持静止。 按下面列出的设置来做。
