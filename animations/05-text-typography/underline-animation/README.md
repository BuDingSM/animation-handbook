# 下划线动画

[在线演示](https://matinmonshizadeh.github.io/animation-handbook/animations/05-text-typography/underline-animation/)

## 它是什么

下划线动画是给链接加的一条会长的底线。平时链接下面没有线，指针移上去时，一条橙色的底线在 0.3 秒里从左边长到和字一样宽，指针移开时，底线的左端往右收，线从右边退出去。线离字 8 像素，粗 3 像素，链接的字是 20 像素的粗体，链接之间隔 56 像素。整个效果很安静，只告诉访客现在指着哪一个链接。

## 什么时候用

- 网站顶部的导航菜单，想让访客一眼看到自己指着哪一项
- 正文里的链接，移上去才出现底线，平时页面更干净
- 标签页和分类切换，底线跟着指针走
- 任何想让链接有一点反馈、又不想太花哨的地方

## 工作原理

底线是链接后面的一条伪元素，平时用 scaleX 压成 0，藏在字下面：

```css
.link::after {
  content: "";
  position: absolute;
  left: 0; right: 0; bottom: -8px; height: 3px;
  background: #ff7a1a;
  transform: scaleX(0);
  transform-origin: right;
  transition: transform 0.3s cubic-bezier(.22, 1, .36, 1);
}
.link:hover::after {
  transform: scaleX(1);
  transform-origin: left;
}
```

移上去时，底线以左端为支点长到 1，移开时，支点换到右端，底线缩回 0，看起来就是左端往右收、线从右边退出去。关键是只给 transform 做动画，不要改宽度：改宽度会让浏览器每一帧都重新排版，改 transform 只走合成，流畅得多。

方向由支点决定：从左长出就是平时支点在右、移上去支点在左；从右长出反过来；从中间长出是两边支点都在中间。演示页的「演示一下」会依次把指针停在每个链接上大约 1 秒，从左到右走一遍。

开启减弱动态效果后，直接显示普通的下划线，不要长出来。

## 关键参数

| 参数 | 默认值 | 效果 |
|-----------|---------|--------|
| 长出的方向 | 从左 | 底线从哪边长出来：从左最常见，从右是反方向，从中间是向两边长 |
| 速度 | 普通 | 底线长满的时间：慢是 0.6 秒，普通 0.3 秒，快 0.15 秒 |
| 底线颜色 | 橙色 | 底线的颜色：橙色、蓝色、绿色，用网站的主色最协调 |
| 粗细 | 普通 | 底线的粗细：细是 2 像素，普通 3 像素，粗 5 像素 |

## 生产注意事项

- **不要改宽度，要改 scaleX。** 宽度动画会触发重排，在低端手机上会掉帧；scaleX 只走合成，始终流畅。
- **底线和字之间留空。** 线离字 8 像素，贴得太近会糊在字上，离得太远又像另一行东西。
- **颜色要和页面协调。** 底线颜色最好取网站的主色，太跳的颜色会抢走链接本身的注意力。
- **不要给已经带下划线的正文再加。** 大段正文里的链接本来就有下划线，再加长出来的线会显得忙乱。
- **触屏上没有悬停。** 手机上没有指针移上去这回事，所以底线动画只是锦上添花，不能是唯一的提示，当前页的链接还要用别的办法标出来。
