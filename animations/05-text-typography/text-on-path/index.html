路径文字

文字沿波浪、弧线或圆形行进。最适合徽章和印章。

1

看效果

它自己在动。暂停可以仔细看，打开慢动作可以看清动作的每个部分。

直线
在路径上 文字附着在这条曲线上 每个刻度开启这句短语的一个副本 字母只在圆点之间显示 每秒滑过四分之一条曲线

内部是这样的：文字附着在一条曲线上，这里用粗线画出。这句短语被重复了，每个刻度标出一个副本从哪里开始；它们一起沿曲线滑动。

「直线」让同样的词沿一条平直线滑动，像滚动条一样。「在路径上」让它们绕着曲线弯曲，所以每个字母都跟着曲线的形状走。

2

试一试

结尾加一个 · 之类的标记，这样重复读起来才顺。

3

复制提示词

把它粘贴到 ChatGPT、Claude 或 Cursor 等 AI 助手里，在你自己的项目中实现这个效果。

给[你的短语]加一段沿曲线行进的文字。定义一次曲线，把文字附着在上面，让每个字母都落在曲线上，然后不断移动文字的起点，让字母像弯成形状的滚动条一样沿曲线行进。重复这句短语，中间用圆点之类的分隔符，直到盖满整条曲线，循环时恰好绕回一个副本，这样就没有跳动。让曲线足够平缓，字母才不会在急弯处挤在一起。如果访客开启了减弱动态效果，让文字静止地停在曲线上。 按下面列出的设置来做。
