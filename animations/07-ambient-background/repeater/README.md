# 重复器

[在线演示](https://animation.xizanghuapi.cn/animations/07-ambient-background/repeater/)

## 它是什么

重复器取一个形状，复制很多份，围成一圈排开，每份都朝外转 90°；整圈慢慢转，每个复制依次变大变小，像一圈波浪在转。颜色按蓝、珊瑚、黄、薄荷的顺序轮换，最初的那一份描一道白边，右上角标出“×数量”。

它是一份形状变成一圈图案的最短路径：不用逐个摆放，只要定好数量、半径和朝向，剩下的都由复制规则算出来。

## 什么时候用

- 加载动画：一圈转动的复制比单个转动的图标更像“正在加载”
- 装饰图案：花朵、放射状图案、背景纹理
- 任何由同一个形状重复排布的东西：花瓣、灯、刻度
- 想让一个简单的形状看起来丰富，又不想多画东西时

## 工作原理

每份复制的位置由它在圈里的序号决定，朝向永远朝外（角度 + 90°）：

```js
for (let i = 0; i < n; i++) {
  const a = rot + i * 2 * Math.PI / n;   // rot: 整圈的旋转
  const x = cx + R * Math.cos(a), y = cy + R * Math.sin(a);
  ctx.save(); ctx.translate(x, y); ctx.rotate(a + Math.PI / 2);
  // 画一份形状
  ctx.restore();
}
```

整圈每 4.7 秒转一圈。每个复制的大小按 `1 ± 0.22` 脉动，每 4.7 秒脉动两次，而且每份比上一份晚 0.55 弧度，所以变大的波峰绕着圈走：

```js
const s = 1 + 0.22 * Math.sin(4 * Math.PI * (t % cycle) / cycle - i * 0.55);
```

颜色按蓝、珊瑚、黄、薄荷的顺序轮换，第 0 份（最初的那一份）描一道白边，右上角用 `×n` 标出数量。rAF 循环按经过的时间推进，慢动作时只取三分之一的时间。开启减弱动态效果后，循环开始时处于暂停状态，画面停在静止的一圈上。

## 关键参数

| 参数 | 默认值 | 效果 |
|-----------|---------|--------|
| 数量 | 12 个 | 复制的份数：4 个排得稀疏，12 个排成密圈 |
| 形状 | 圆棒 | 圆棒是 24×60 的圆角棒；花瓣是椭圆花瓣，排出来像一朵花；圆点像一圈灯 |
| 速度 | 普通 | 整圈转一圈的时间：慢是 8 秒，普通 4.7 秒，快是 2.5 秒 |
| 波浪 | 开 | 每个复制依次变大变小，像波浪绕圈走；关掉后所有复制一样大，只有整圈在转 |

## 生产注意事项

- **数量和半径要配着调。** 数量多了半径不变，复制会挤在一起；数量少了半径不变，圈中间会空一大块。
- **脉动的相位差决定波浪的方向。** 每份晚 0.55 弧度，波峰就顺着圈走；相位差改成负的，波浪就反向走；相位差改成 0，所有复制一起变大，波浪就没了。
- **朝向要朝外。** 每份转 `角度 + 90°` 才像花瓣或射线；不转的话，所有复制都朝着同一个方向，圈看起来是歪的。
- **最初那份的白边是定位用的。** 转起来之后，访客靠那道白边才能看出圈在转；没有它，一圈相同的复制转起来和没转几乎没区别。
- **开启减弱动态效果时显示静止的一圈。** 对动效敏感的访客不该被持续的旋转打扰。
- **GSAP 等价写法：** 把一份形状放进一个容器，复制 `n` 份，每份 `rotation: i * 360 / n` 并沿半径摆放，再让容器整体旋转；脉动用 `scale` 加 `stagger` 错开。
