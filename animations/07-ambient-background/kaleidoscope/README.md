# 万花筒

[在线演示](https://animation.xizanghuapi.cn/animations/07-ambient-background/kaleidoscope/)

## 它是什么

万花筒把画面绕着中心切成 8 面，每面 45°，隔一面左右翻转，拼成镜像对称；每面里放十几个圆、菱形和三角形，颜色固定四种，从中心向外走，越往外越大、越转，走到边缘回到中心重新来；整幅图案慢慢转，中间放一颗一胀一缩的白色八角星。

它和普通旋转图案的区别在于镜像：只转不镜像，每面都一样，看起来像风车；隔一面翻转一次，左右两边对上了，才是万花筒。

## 什么时候用

- 开场背景：演出、音乐、活动页面的第一屏
- 徽标后面的装饰：让一个静态徽标周围一直有东西在动
- 梦幻的转场：两个场景之间用一幅对称图案过渡
- 任何需要一幅反复看也不腻的图案的地方

## 工作原理

画面绕中心切成 8 个 45° 的扇形，奇数号扇形画之前先左右翻转一次：

```js
for (let w = 0; w < wedges; w++) {
  ctx.save(); ctx.translate(cx, cy); ctx.rotate(rot + w * wa);
  if (w % 2 === 1) ctx.scale(-1, 1);   // 隔一面镜像
  // 画这一面里的图形
  ctx.restore();
}
```

每面里有 13 个图形（圆、菱形、三角形，四种颜色，位置和大小用固定种子随机生成，所以每次打开都是一样的图案）。每个图形从中心向外走，每 4.7 秒走完一个半径，走到边缘回到中心：

```js
let r = (s.r0 + 300 * (u / cycle)) % 300;
const size = (5 + 0.1 * r) * s.sf;   // 越往外越大
// 旋转 0.02 弧度/像素，前 30 像素淡入，后 70 像素淡出
```

整幅图案每 4.7 秒转 90°——正好是两面的宽度，所以循环首尾接得上。中心的白色八角星每 4.7 秒脉动两次，半径在 20 ± 4 之间变化。

rAF 循环按经过的时间推进，慢动作时只取三分之一的时间。开启减弱动态效果后，循环开始时处于暂停状态，画面停在静止的图案上。

## 关键参数

| 参数 | 默认值 | 效果 |
|-----------|---------|--------|
| 对称面数 | 8 面 | 画面切成的扇形数：4 面图案粗大，12 面图案细碎；每面是 360° 除以面数 |
| 速度 | 普通 | 图案转 90° 的时间：慢是 9 秒，普通 4.7 秒，快是 2.5 秒 |
| 图形多少 | 普通 13 个 | 每面里的图形数：疏是 8 个，密是 20 个 |
| 中心星星 | 开 | 中间的白色八角星，一胀一缩；关掉后中心是空的 |

## 生产注意事项

- **面数必须是偶数，镜像才对得上。** 隔一面翻转一次，要求面数是偶数；奇数面数会让最后一面和第一面接不上，对称破掉。
- **整体旋转的角度要是两面的宽度。** 每 4.7 秒转 90°（8 面时两面的宽度），循环首尾才接得上；转任意角度会在循环点跳一下。
- **图形的位置要用固定种子随机。** 每次打开图案都不一样，访客会觉得页面不稳定；固定种子后图案每次都一样，也方便调试。
- **淡入淡出要留够距离。** 图形在中心突然出现、在边缘突然消失都会闪一下；前 30 像素淡入、后 70 像素淡出， motion 才顺滑。
- **别放在正文后面。** 万花筒的对比度和运动都很强，放在文字后面会让文字没法读；它只适合做背景或开场。
- **开启减弱动态效果时显示静止的图案。** 对动效敏感的访客不该被持续旋转的对称图案打扰。
- **GSAP 等价写法：** 万花筒不适合用 DOM 做——每面十几个图形、8 面镜像，画布是更直接的工具；用 Canvas 按上面相同的规则画，再用 `requestAnimationFrame` 推进时间。
