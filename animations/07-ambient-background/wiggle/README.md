# 摆动

[在线演示](https://animation.xizanghuapi.cn/animations/07-ambient-background/wiggle/)

## 它是什么

摆动让一个铃铛（或一个红点标记）绕着顶部的支点不停地小幅度抖动。抖动不是一次撞击，而是一直持续的细碎晃动：角度是四个正弦波叠加起来的，频率各不相同，所以看起来不规则、没有停顿；位置也跟着轻轻晃。铃铛的舌头往反方向摆，两边还有两道忽明忽暗的白色振动弧，表示它正在响。

幅度默认大约 10°，最大约 13.5°——刚好够一眼注意到，又不会晃得人眼花。

## 什么时候用

- 通知铃铛、来电提示等需要马上被注意到的地方
- 图标角上的待处理标记，有新消息时提醒访客
- 任何“这里有事，等你处理”的小提示
- 想给画面一点坐立不安、手持感的装饰

## 工作原理

角度是四个正弦波的和，每 4.7 秒分别是 23、31、43、59 个整周期，振幅 0.085、0.065、0.05、0.035 弧度：

```js
const SINES = [[23, 0.085, 0.3], [31, 0.065, 1.9], [43, 0.05, 4.2], [59, 0.035, 2.6]];
function wsum(u, arr) {
  const w = 2 * Math.PI / cycle;
  return arr.reduce((s, a) => s + a[1] * Math.sin(w * a[0] * u + a[2]), 0);
}
const rot = wsum(u, SINES) * amp;
```

每个频率在 4.7 秒里都是整数个周期，所以循环首尾接得上；四个周期数互质，所以抖动看起来没有规律。位置也用同样的方法晃：横向是 29、47、61 个周期（振幅 4、3、2 像素），纵向是 37、53 个周期（振幅 2.4、1.8 像素）。

铃铛绕着顶部支点转，舌头（珊瑚色圆点）放在 `-rot * 70` 的位置，所以总是往反方向摆。两边的振动弧是两道圆弧，透明度跟着 `|sin|` 忽明忽暗。

rAF 循环按经过的时间推进，慢动作时只取三分之一的时间。开启减弱动态效果后，循环开始时处于暂停状态，画面停在静止的铃铛上。

## 关键参数

| 参数 | 默认值 | 效果 |
|-----------|---------|--------|
| 幅度 | 中 | 抖动的幅度倍数：小是 0.5 倍，大是 1.6 倍；中档时四个正弦波叠加最大约 13.5° |
| 速度 | 普通 | 一个循环的时间：慢是 7 秒，普通 4.7 秒，快是 3 秒 |
| 摆动对象 | 铃铛 | 铃铛是黄色铃铛加舌头；红点标记是带感叹号的红色圆点，适合放在图标角上 |
| 振动弧 | 开 | 铃铛两边的白色振动弧，忽明忽暗地表示它在响 |

## 生产注意事项

- **幅度别贪大。** 超过 15° 的摆动看起来像故障，而不是提醒；需要更强的提醒时，改用颜色或数量标记，而不是把幅度调到最大。
- **只给旋转和位移做动画。** 铃铛用 `transform` 的旋转和平移来抖，不改布局属性，这样才流畅，也不会推开周围的元素。
- **支点要在顶部。** 铃铛绕着顶部的挂点转才像真的在响；绕中心转会像在原地打转。
- **别让它一直抖个没完。** 提醒的意义在于“有新东西”，响过一阵就该停下来，或者只在有未读内容时才抖；整页常驻的抖动很快会被访客无视。
- **开启减弱动态效果时显示静止的铃铛。** 对动效敏感的访客不该被持续的抖动打扰。
- **GSAP 等价写法：** 用四个不同频率的正弦函数叠加驱动 `rotation`，而不是一个来回的补间——单个正弦来回摆看起来太规律，一眼就是机械的。
