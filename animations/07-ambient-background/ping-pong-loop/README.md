# 往返循环

[在线演示](https://matinmonshizadeh.github.io/animation-handbook/animations/07-ambient-background/ping-pong-loop/)

## 它是什么

往返循环让一个圆角方块从一头走到另一头，再沿着同一条路倒着走回来，周而复始，中间没有跳回开头的断点。去的时候方块转一圈，回来的时候倒着转回去；下面配一条播放条：正放时是蓝色、写着“正放”，倒放时是珊瑚色、写着“倒放”，进度条和黄色圆点跟着走。两头各立一根柱子标出折返点。

它和普通循环的区别就在折返那一下：普通循环走到头会突然跳回开头，眼睛能看到断点；往返循环是原路返回，所以看起来永远在动、永远不断。

## 什么时候用

- 加载指示：不知道还要等多久时，来回走比转圈更耐看
- 等待中的装饰：页面空闲时让 something 一直动着
- 来回展示的小元素：在两头之间反复比较或切换
- 任何想一直重复、又不想让访客看到跳回开头的动作

## 工作原理

进度 `g` 在 0 到 1 之间走直线：前半个周期从 0 走到 1，后半个周期从 1 回到 0：

```js
function gOf(u) {
  const c = 2 * oneway, q = mod(u, c) / c;
  return q < 0.5 ? 2 * q : 2 - 2 * q;   // 0→1→0
}
```

方块的位置和旋转都只由 `g` 决定，所以去和回走的是同一条路：

```js
function pos(g, x0, x1, base, hop) {
  return [x0 + (x1 - x0) * g, base - hop * Math.abs(Math.sin(3 * Math.PI * g))];
}
// 旋转 g * 2π：g 倒着走时，旋转也跟着倒回去
```

方块沿着三座小拱跳过去，拱的高度是 `hop * |sin(3πg)|`；平移走法则把拱的高度换成 0，贴着地面走。身后有四个残影，各晚 0.045 秒，透明度 0.1 到 0.4，让运动看起来更顺滑。

下面的播放条跟着 `g` 走：正放时蓝色，倒放时珊瑚色，进度条和圆点都按 `g` 定位。rAF 循环按经过的时间推进，慢动作时只取三分之一的时间。开启减弱动态效果后，循环开始时处于暂停状态，方块静止在中间。

## 关键参数

| 参数 | 默认值 | 效果 |
|-----------|---------|--------|
| 单程时间 | 普通 1 秒 | 从一头走到另一头的时间：慢是 2 秒，快是 0.5 秒；一整趟往返是单程的两倍 |
| 形状 | 方块 | 方块是带白点的薄荷色圆角方块；圆点更像加载指示 |
| 走法 | 跳跃 | 跳跃沿着三座小拱走；平移贴着地面走，没有上下起伏 |
| 残影 | 开 | 身后四个依次变淡的残影，关掉后运动看起来更干脆 |

## 生产注意事项

- **单程别太短。** 0.5 秒以下方块会像在抽搐；加载指示一般 1 秒单程最舒服。
- **去和回必须是同一条路。** 往返循环的全部意义就是没有断点；如果回程走了另一条路，它就退化成普通循环了。
- **旋转要跟着进度走，而不是跟着时间走。** 旋转角度由 `g` 决定，倒放时 `g` 减小，旋转自然倒回去；用时间驱动旋转，倒放时会继续往前转。
- **残影的数量和间隔要固定。** 残影按时间差取过去的进度，间隔太密会糊成一片，太疏会像掉帧。
- **开启减弱动态效果时显示静止在中间的方块。** 对动效敏感的访客不该被持续的来回运动打扰。
- **GSAP 等价写法：** `gsap.to(el, { x: end, duration: 1, yoyo: true, repeat: -1 })`——`yoyo` 就是往返循环，`repeat` 不加 `yoyo` 会在每次结束时跳回开头。
