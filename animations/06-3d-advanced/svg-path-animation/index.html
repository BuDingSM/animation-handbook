SVG 路径动画

线条画一笔一笔自己画出来。适合图标和标志。

1

看效果

它自己播放。打开慢动作能看清每一步。

淡淡的：每条完整的线，都被它的虚线藏起来了 · 1、2、3：它们画出来的顺序 1、2、3：它们画出来的顺序 填充 已经画好了 自己画出来 一秒时

看内部：每条线从一开始就完整存在，只是被一条和线一样长的虚线藏起来了；把虚线滑走，就能从圆点开始按编号顺序露出线来。

已经画好了会一下子显示画完的图。自己画出来会一条一条从一端露出线来，像手绘一样。

复制提示词

把它粘贴给 ChatGPT、Claude 或 Cursor 这类 AI 助手，在你自己的项目里做出这个效果。

给[你的图标、标志或签名，画成 SVG 线条]加一条自己画出来的线。量出每条线的长度，用一条和线一样长的虚线把它藏起来，再把虚线滑走，线就从一端画到另一端，像手绘一样。多条线一条接一条画，每条比前一条晚一点开始。如果设置里有，线画完后给形状填色。画完的样子从一开始就要能被屏幕阅读器读到。如果访客打开了减弱动态效果，就直接显示画好的图。 按下面列出的设置来做。
